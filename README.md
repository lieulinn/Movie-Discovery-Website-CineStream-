# CineStream — Movie Discovery Website

CineStream adalah platform penjelajahan katalog film interaktif bergaya antarmuka gelap (Dark Cinema UI) modern. Proyek ini dibangun untuk mendemonstrasikan kemampuan pengembangan antarmuka web yang responsif, performatik, dan kaya akan transisi visual tanpa ketergantungan framework eksternal.

---

## Fitur Utama

- **Featured Hero Spotlight**: Tampilan utama film pilihan dengan aksi cepat untuk melihat rincian film.
- **Kategori & Pengelompokan**: Katalog terstruktur berdasarkan Trending, Popular, dan Top Rated.
- **Filter Berbasis Genre**: Fitur filter cepat menggunakan tombol pill genre (Action, Sci-Fi, Drama, dll.).
- **Live Search Filter**: Pencarian real-time berdasarkan judul atau genre film.
- **Modal Detail Film**: Popup modal interaktif yang menampilkan poster, sinopsis lengkap, daftar pemeran (cast), rating, dan genre.
- **Responsif & Interactive Animation**: Animasi hover pada kartu poster film serta tata letak yang adaptif untuk perangkat seluler.

---

## Teknologi yang Digunakan

- **HTML5**: Struktur halaman katalog semantik.
- **CSS3**: Tata letak modern (Flexbox & CSS Grid), CSS Variables, efek Glassmorphism, dan transisi animasi.
- **JavaScript (ES6+)**: Pengelolaan data lokal (Array-based DB), manipulasi DOM, filter pencarian, serta logika modal interaktif.
